# Рейтинг пилотов F1

> Неофициальный фан-проект: не связан с Formula 1, FIA и командами. Названия и товарные знаки
> принадлежат их владельцам. Сайт пересчитывается автоматически — см. «Сайт и автообновление».

Общий рейтинг пилотов Формулы-1 за 2011–2026 годы (эпоха шин Pirelli и DRS) и по отдельным
сезонам. Начальный сезон задаётся в `config.py` (`FIRST_SEASON`). Итоговый балл 0–100
складывается из восьми групп признаков:

| Группа | Признаки |
|---|---|
| Результаты | очки за гонку, победы, подиумы, место в чемпионате |
| Сверх уровня машины | очки и места сверх того, что обычно привозит машина такого ранга; «яркие гонки» |
| Квалификация | поулы, выход в Q3, отставание от лучшего времени, среднее место |
| Темп в гонке | отставание от медианы поля на чистых кругах, стабильность темпа |
| Борьба | первый круг, обгоны и пропущенные обгоны на трассе, позиции сверх ожидаемого за гонку |
| Аккуратность | свои аварии и развороты, столкновения по решению стюардов, другие штрафы (поломки и чужие столкновения не в счёт) |
| Против напарника | три модели сети напарников (квала, темп, финиш), доля очков команды |
| Карьера (только сводка) | титулы, лучший сезон, сезоны в топ-5 |

Уровень машины на каждом этапе — темп, который она показала бы со средним пилотом: средний темп
двух её пилотов на чистых кругах с поправкой на их навык из модели напарников, сглаженный по
соседним этапам. По отрыву от лучшей машины считается, сколько очков такая машина обычно привозит,
и пилот получает разницу между фактом и ожиданием — очки сверх среднего пилота на той же машине.

**Проверки рейтинга** (`validate.py`, каждый прогон, таблица — в методике на странице):
повторяемость групп внутри сезона (нечётные этапы против чётных) и то, сохраняется ли балл
пилота в соседних сезонах после смены команды (группа, которая меряет пилота, сохраняется;
смена названия команды переходом не считается). Пресет весов «По данным» даёт группе вес
пропорционально этой связи. Без поправки на навык «Сверх уровня машины» после смены команды
не сохранялась вовсе (−0,15), с поправкой — самая устойчивая из групп (около 0,4).

«Аккуратность» складывается из трёх видов происшествий без пересечений: свои аварии и развороты,
столкновения по решению стюардов FIA (с 2019 года, `ingest/fia.py` — заголовки документов
«Offence / Infringement — Car N — causing a collision») и другие штрафы по времени. Столкновение
засчитывается только наказанному; сошедший из-за чужой ошибки ничего не теряет, и его дуэль
с напарником не учитывается, а наказанный сошедший получает в дуэли поражение (`clean/collisions.py`).
В карточке пилота под группой перечислены сами гонки.

**Дождь и типы трасс** — справка в карточке, в балл не входят: проверка показывает, что они
повторяются слабо (`features/conditions.py`). Дождевые гонки размечены вручную по отчётам
в `annotations/wet_races.yaml`; для новых гонок подсказку дают осадки из архива Open-Meteo
(`ingest/weather.py`), а пайплайн пишет в лог, какие гонки проверить. Тип трассы: уличные — по F1DB,
автодромы — пополам по средней скорости лучшего круга.

В карточке пилота — краткая биография: вводная часть статьи Википедии (русской, если она есть)
со ссылкой на статью и лицензию CC BY-SA 4.0. Ссылку на статью даёт Jolpica.

**Граф напарников.** Модели сравнивают пилотов через все цепочки напарников сразу; связи весят
по числу совместных гонок, подменные выступления (до 3 гонок за команду в сезоне) — вполовину.
Несколько пилотов 2011–2015 ездили только друг с другом (Альгерсуари и Буэми, Чилтон и Бьянки,
Мерхи, Росси и Стивенс): это отдельные группы, их «Против напарника» ни с кем больше не сравнить.
Надёжность сравнения считается как эффективное сопротивление в сети, где каждая совместная гонка —
проводник: на странице видно, сколько гонок прямой дуэли «стоит» сравнение любых двух пилотов,
какой путь между ними самый сильный и какие пилоты — «мосты», без которых сеть распадается.

Каждый признак переводится в z-оценку среди пилотов охвата, доли сжимаются к среднему
(мало гонок — меньше доверия), балл = 50 + 15·z. Веса групп меняются ползунками на странице.

**Вилки балла и места.** Рейтинг пересчитывается 200 раз на случайно перевыбранных этапах:
в каждом сезоне уикенды берутся с повторениями (гонка и спринт всех пилотов целиком), чемпионат
и титулы пересчитываются по очкам выбранных этапов, группа «Против напарника» берёт один из
вариантов модели напарников, а 10 воображаемых гонок, которыми сжимаются доли, «проезжает»
случайный пилот пула. Все пересчёты меряются той же линейкой (средние и разбросы по пулу), что
и основной балл. На странице: вилка балла и диапазон мест в 80% пересчётов, шанс быть первым,
«≈» у пар, чей порядок держится меньше чем в 60% пересчётов. Страница хранит z групп каждого
пересчёта и собирает вилки заново при любых весах.

## Быстрый старт (PowerShell, из корня проекта)

```powershell
.\.venv\Scripts\python.exe -m pip install -c constraints.txt -e .
.\.venv\Scripts\python.exe -I -m rating_f1.pipeline
```

Данные сайта в репозитории не хранятся: их пишет пайплайн (`web/data`). Первый запуск
скачивает всё — 16 сезонов Jolpica, архивы F1DB и RaceData, документы FIA, осадки,
биографии — и идёт 15–20 минут, дальше данные берутся из кэша `data/raw`. Потом откройте
`web/index.html` двойным кликом: данные лежат в `web/data/data.js`, поэтому сервер не нужен;
графики подгружают ECharts из CDN. `constraints.txt` закрепляет версии библиотек, с которыми
пайплайн проверен.

Флаг `-I` запускает Python в изолированном режиме: пайплайн читает скачанный архив F1DB,
и так из папки с данными точно ничего не импортируется.

## Сайт и автообновление

Сайт собирает и публикует на GitHub Pages workflow «Обновление рейтинга»
(`.github/workflows/pages.yml`): каждый понедельник в 06:00 UTC (после гоночных выходных),
после каждого push в `main` и по кнопке Run workflow на вкладке Actions. Он ставит Python
с версиями из `constraints.txt`, восстанавливает кэш скачанных данных, дописывает недостающее
из архива начальных данных `data/seed.zip` (прошлые сезоны Jolpica, документы FIA, осадки,
биографии — около 1 МБ), запускает пайплайн и выкладывает папку `web/`. Архив нужен, потому
что кэш GitHub удаляется через 7 дней без обращений, а Jolpica с общих адресов GitHub часто
отвечает отказом: без архива первый запуск — около 45 минут. Проверка прогнозом при ручном
запуске считается заново, в остальных — берётся из прошлого прогона, пока ей меньше 35 дней.
Адрес сайта — `https://<логин>.github.io/<репозиторий>/`.

На странице каждого запуска (Summary) — отчёт `python -I -m rating_f1.report`: по какой гонке
данные, топ периода и последнего сезона, таблица проверок рейтинга. Так видно, как каждая
правка меняет метрики.

Настройка: Settings → Pages → Source: GitHub Actions. Если в репозитории 60 дней не было
коммитов, GitHub выключает запуск по расписанию — включить его можно на вкладке Actions.

## Команды

| Команда | Что делает |
|---|---|
| `python -I -m rating_f1.pipeline` | докачивает текущий сезон и свежий релиз F1DB, пересчитывает всё, ~5 мин |
| `... --offline` | без сети, из `data/processed` |
| `... --refresh` | перекачать все сезоны Jolpica |
| `... --no-backtest` | пропустить проверку прогнозом (быстрее) |
| `... --reuse-backtest` | проверку прогнозом взять из прошлого прогона, если ей меньше 35 дней |
| `python -I -m rating_f1.seed pack` | пересобрать архив начальных данных `data/seed.zip` (после нового сезона) |
| `python -I -m rating_f1.seed unpack` | дописать в `data/raw` недостающие файлы из архива — первый запуск быстрее |
| `... --no-intervals` | без вилок балла и места (минус ~2,5 мин) |
| `python -m rating_f1.ingest.fastf1_laps --season 2026 --round 19` | круги через FastF1 (нужна подписка F1 TV) |

## Что где лежит

```
src/rating_f1/
  ingest/jolpica.py      Jolpica API: результаты, квалификации, спринты (кэш страниц)
  ingest/f1db.py         F1DB: причины сходов, штрафы, лучшие круги, таблицы чемпионатов
  ingest/racedata.py     TracingInsights RaceData: позиция и время каждого круга, пит-стопы
  ingest/wiki.py         краткие биографии из Википедии (кэш data/raw/wiki, раз в 30 дней)
  ingest/fia.py          решения стюардов FIA о столкновениях (кэш data/raw/fia)
  ingest/weather.py      осадки на трассе в часы гонки и перед стартом из Open-Meteo
  clean/collisions.py    виновник или пострадавший в сходах после столкновений
  features/conditions.py дождь и типы трасс для карточки пилота
  ingest/fastf1_laps.py  круги через FastF1 (нужна подписка F1 TV; сейчас не используется)
  tables.py              таблицы Parquet + база data/f1.duckdb
  clean/                 классификация сходов, уточнение статусов по F1DB, ручные правки
  features/quali.py      гэпы к напарнику в квалификации
  features/race.py       гоночные дуэли с напарником
  features/laps.py       по кругам: темп, стабильность, первый круг, обгоны, темп с напарником
  features/car_level.py  уровень машины со средним пилотом и результат относительно него
  features/stats.py      статистика пилота в каждой гонке и сводки
  features/stints.py     подменные выступления: половинный вес в моделях и графе
  models/teammate.py     навык: Ridge с цепочкой сезонов, Брэдли–Терри для гонок
  models/season.py       выступление в сезоне относительно машины
  composite.py           общий рейтинг: признаки → группы → 0–100, сверка с экспертами
  intervals.py           вилки балла и места: пересчёты на перевыбранных этапах
  validate.py            проверки рейтинга: повторяемость, сохранность при смене команды
  report.py              отчёт о прогоне в Markdown — для страницы запуска в GitHub Actions
  seed.py                архив начальных данных data/seed.zip: собрать и распаковать
  graph.py               граф напарников: раскладка, надёжность сравнения, «мосты»
  evaluate.py            проверка прогнозом модели напарников
  export.py              JSON и data.js для сайта
  pipeline.py            весь цикл одной командой
annotations/overrides.yaml        ручные правки: причины сходов, исключения
annotations/expert_rankings.yaml  опросы руководителей команд 2021–2025 (только для сверки)
annotations/wet_races.yaml        дождевые гонки, проверенные по отчётам
web/                              страница: index.html, app.js, style.css; data/ пишет пайплайн
.github/workflows/pages.yml       пересчёт по расписанию и публикация на GitHub Pages
constraints.txt                   версии библиотек, с которыми проверен пайплайн
data/seed.zip                     архив начальных данных: прошлые сезоны, которые уже не меняются
```

В базе `data/f1.duckdb` лежат все промежуточные таблицы: `race_records` (пилот × гонка
со всеми признаками), `scores` (баллы по охватам, с вилками при весах по умолчанию:
`rating_lo/hi`, `rank_lo/hi`, `p_top1`, `p_above_next`), `teammate_ratings`, `race_duels` и другие.

## Источники данных

- **Jolpica F1 API** (преемник Ergast) — результаты, квалификации, спринты, годы дебюта.
  Лимит — 500 запросов в час, поэтому клиент делает паузы, а ответы кэшируются в `data/raw`.
- **F1DB** (github.com/f1db/f1db, CC BY 4.0) — причины сходов (Jolpica с 2023 года пишет
  у всех просто «Retired»), штрафы, лучшие круги, гонщик дня, таблицы чемпионатов.
  Релиз выходит после каждой гонки, скачивается целиком (~5 МБ).
- **TracingInsights RaceData** (github.com/TracingInsights/RaceData) — архив в формате Ergast
  (~10 МБ): позиция и время каждого пилота на каждом круге, пит-стопы. Обновляется после гонок.
- **Опросы руководителей команд F1** — только для сверки сезонного топ-10.
- **Википедия** (API MediaWiki) — вводная часть статьи о пилоте для краткой биографии,
  CC BY-SA 4.0. Без сети (`--offline`) берётся из кэша `data/raw/wiki/bios.json`.
- **Документы FIA** (fia.com/documents, с 2019 года) — заголовки решений стюардов: кто наказан
  за столкновение. Первая загрузка — около 4 минут (≈190 страниц этапов с паузой в секунду),
  дальше только новые этапы.
- **Open-Meteo** (архив реанализа, без ключа, CC BY 4.0) — осадки по часам на трассе: подсказка
  для разметки дождевых гонок.
- **FastF1 ≥ 3.9** отдаёт хронометраж только с аккаунтом Formula 1 и подпиской F1 TV
  (`F1_USERNAME`, `F1_PASSWORD`). Шины (составы, износ) есть в сезонных репозиториях
  TracingInsights (15–20 ГБ каждый, с телеметрией) и в OpenF1 (с 2023 года).

## Лицензии и данные

Данные и тексты на сайте подчиняются лицензиям источников: F1DB и Open-Meteo — CC BY 4.0,
биографии из Википедии — CC BY-SA 4.0 (ссылка на статью — в карточке пилота); данные Jolpica,
TracingInsights RaceData и заголовки документов FIA используются с указанием источника.
В репозитории хранится только архив `data/seed.zip` с ответами источников за прошлые сезоны —
чтобы не нагружать их повторной загрузкой; всё остальное пайплайн получает сам.
